BIRTHDAY WEBSITE VERSION 2 — TANPA KUIS

Fitur kuis sudah dihapus.
Sebagai gantinya tersedia:
- Tap-to-reveal pesan hati
- Taman interaktif berisi pesan
- Mini game mencari hati rahasia
- Galeri scrapbook dan lightbox
- Surat cinta, musik, countdown, dan ending cinematic

Cara membuka:
1. Ekstrak ZIP.
2. Buka index.html di browser atau gunakan VS Code + Live Server.
3. Edit CONFIG di script.js untuk mengganti nama, tanggal, foto, musik, dan pesan.
